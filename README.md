# Api_Ecommerce_Fruit

API de E-commerce para venda de frutas.

## Resumo Gerado por IA

Este repositório contém uma API de E-commerce desenvolvida em C# e .NET para a venda de frutas. A API utiliza a arquitetura de Endpoints Mínimos, o que a torna leve e performática. O projeto está configurado para ser executado em um ambiente Docker, facilitando o deploy e a escalabilidade.

### Tecnologias Utilizadas

*   C#
*   .NET
*   Endpoints Mínimos
*   Docker
*   Entity Framework Core
*   PostgreSQL

### Estrutura do Projeto

*   **Fruit.Api/Domain:** Contém as entidades da aplicação.
*   **Fruit.Api/Endpoints:** Contém os Endpoints da API.
*   **Fruit.Api/Dockerfile:** Arquivo para a criação da imagem Docker da aplicação.
*   **Fruit.Api/Program.cs:** Arquivo principal da aplicação.
*   **Fruit.Api/appsettings.json:** Arquivo de configuração da aplicação.
